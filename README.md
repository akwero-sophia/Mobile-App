# Mobile-App

## Overview

StudyTracker is a simple Flutter mobile application that helps students track their study tasks. Users can add tasks, mark them as completed, and delete them.

## Features

- Add new study tasks
- Mark tasks as completed
- Delete tasks
- View total and completed tasks

## Technologies Used

- Flutter
- Dart
- Material UI

## How to Run the App

1. Install Flutter SDK
2. Clone this repository
3. Run `flutter pub get`
4. Run `flutter run`

## Code Structure

- main.dart – contains app logic, UI, and task management
- StudyTask class – represents a study task
- Stateful widget manages dynamic updates
