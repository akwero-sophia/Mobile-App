# Study Tracker Mobile Web App

## Overview

This is a mobile-responsive Study Tracker application built using HTML, CSS, and JavaScript. It allows users to add, complete, and delete study tasks.

## Features

- Add study tasks
- Mark tasks as completed
- Delete tasks
- View task completion statistics

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download the project folder
2. Open index.html in a browser

## Code Structure

- index.html – structure of the app
- style.css – styling and mobile layout
- script.js – task logic and functionality
